# Claude Code Guide

Project docs live here.

Start map:

- `ARCHITECTURE.md`: system boundaries and the live suggestion loop.
- `DEVELOPMENT.md`: build, test, and private-beta release process.
- `product/`: executable proof manifests, beta readiness, privacy, and compatibility evidence.
- `diagnostics/`: local diagnostic workflows and generated run-bundle rules.
- `evals/`: reproducible reports consumed by tests or proof scripts.
- `research/`: current runtime decisions that source or tests still reference.

Rules:

- Keep docs short and decision-oriented.
- Do not create dated planning, comparison, or scorecard stacks without an executable consumer.
- Do not imply external model servers are required.
- Separate proven behavior from plans or guesses.
- Do not paste private typed text or raw screenshots into docs.
