# Research digests

Short Tilde-specific notes on external papers. The index is
[`docs/reading-list.md`](../reading-list.md). Read the digest first. Fetch the
source only when the digest is not enough.

These notes are original words. They do not copy paper text. Each one says
what the work did, which numbers matter, what transfers to Tilde, and what
does not. Ideas here are hypotheses. A measured result graduates to
[`docs/model-lessons.md`](../model-lessons.md) and, when it is reusable, to
the Learning Ledger.

Do not check in PDFs, prompts, personal writing, screen text, or local paths.
