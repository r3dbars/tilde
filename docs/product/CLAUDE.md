# Claude Code Guide

Product decision docs live here.

Rules:

- Keep language plain.
- Tie decisions back to the typing loop: useful, calm, safe, and easy to stop.
- Keep proof gates honest. Pending proof stays pending.
- Do not add a new plan or scorecard when a current proof artifact can carry the truth.
